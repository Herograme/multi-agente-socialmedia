# GDD Review Checklist

Checklist completo para revisao de Game Design Documents (GDD) de jogos Roblox.

**Responsavel:** @game-designer
**Revisores:** @market-analyst, @monetization-strategist
**Score minimo para aprovacao:** 80%

---

## 1. Vision & Pillars (20 pontos)

### 1.1 Game Vision (10 pontos)
- [ ] **Vision statement clara** - Uma frase que define a essencia do jogo (2 pts)
- [ ] **Unique Selling Proposition (USP) definida** - O que diferencia dos competidores (2 pts)
- [ ] **Target audience especificado** - Idade, regiao, perfil do jogador (2 pts)
- [ ] **Emotional hooks identificados** - Que emocoes o jogo evoca (2 pts)
- [ ] **Reference games listados** - Inspiracoes com explicacao do que sera usado de cada (2 pts)

### 1.2 Design Pillars (10 pontos)
- [ ] **3-5 pillars definidos** - Principios guia do design (3 pts)
- [ ] **Cada pillar tem descricao** - Explicacao de como afeta decisoes (3 pts)
- [ ] **Pillars sao mensuraveis** - Como validar se esta sendo seguido (2 pts)
- [ ] **Pillars nao conflitam** - Coerencia entre os principios (2 pts)

**Score Vision & Pillars:** ____/20

---

## 2. Core Loop (20 pontos)

### 2.1 Loop Principal (12 pontos)
- [ ] **Loop claramente diagramado** - Fluxo visual ou textual do ciclo (3 pts)
- [ ] **Tempo de loop definido** - Duracao de uma iteracao completa (2 pts)
- [ ] **Acoes do jogador listadas** - O que o jogador faz em cada fase (2 pts)
- [ ] **Feedback imediato descrito** - Resposta instantanea as acoes (2 pts)
- [ ] **Recompensa do loop clara** - O que o jogador ganha ao completar (3 pts)

### 2.2 Loops Secundarios (8 pontos)
- [ ] **Meta-progressao definida** - Como sessoes conectam (2 pts)
- [ ] **Loop diario identificado** - Razao para voltar todo dia (2 pts)
- [ ] **Loop social presente** - Interacao com outros jogadores (2 pts)
- [ ] **Loops interconectados** - Como um loop alimenta outro (2 pts)

**Score Core Loop:** ____/20

---

## 3. Systems Design (15 pontos)

### 3.1 Sistemas Core (8 pontos)
- [ ] **Todos os sistemas listados** - Lista completa de sistemas do jogo (2 pts)
- [ ] **Cada sistema tem descricao** - Proposito e funcionamento (2 pts)
- [ ] **Interacoes entre sistemas** - Como sistemas se conectam (2 pts)
- [ ] **Complexidade adequada** - Nem muito simples, nem overwhelming (2 pts)

### 3.2 Documentacao de Sistemas (7 pontos)
- [ ] **Rules de cada sistema** - Regras claras e nao-ambiguas (2 pts)
- [ ] **Edge cases considerados** - Situacoes limites documentadas (2 pts)
- [ ] **Valores iniciais definidos** - Parametros base para balanceamento (2 pts)
- [ ] **Formulas documentadas** - Calculos matematicos explicados (1 pt)

**Score Systems Design:** ____/15

---

## 4. Progression Curve (15 pontos)

### 4.1 Player Progression (8 pontos)
- [ ] **Curva de dificuldade mapeada** - Grafico ou descricao da progressao (2 pts)
- [ ] **Milestones definidos** - Momentos importantes na jornada (2 pts)
- [ ] **Onboarding planejado** - Primeiros 5-10 minutos detalhados (2 pts)
- [ ] **Endgame considerado** - O que acontece apos "zerar" (2 pts)

### 4.2 Content Pacing (7 pontos)
- [ ] **Unlock schedule claro** - Quando cada feature e liberada (2 pts)
- [ ] **Tempo estimado para cada fase** - Horas para atingir milestones (2 pts)
- [ ] **Novidades regulares** - Surpresas ao longo da experiencia (2 pts)
- [ ] **Sem dead zones** - Nao ha momentos vazios de conteudo (1 pt)

**Score Progression Curve:** ____/15

---

## 5. Economy Balance (10 pontos)

### 5.1 Currency Design (5 pontos)
- [ ] **Moedas definidas** - Soft/Hard currency e propositos (1.5 pts)
- [ ] **Earn rates calculados** - Quanto jogador ganha por hora (1.5 pts)
- [ ] **Sinks identificados** - Onde moeda e consumida (1 pt)
- [ ] **Equilibrio faucet/sink** - Economia sustentavel (1 pt)

### 5.2 Value Perception (5 pontos)
- [ ] **Pricing tiers definidos** - Faixas de preco para items (1.5 pts)
- [ ] **Valor relativo claro** - Jogador entende tradeoffs (1.5 pts)
- [ ] **Economia nao inflacionaria** - Valores mantem sentido ao longo do tempo (1 pt)
- [ ] **Premium vs Free balance** - Jogador free se sente completo (1 pt)

**Score Economy Balance:** ____/10

---

## 6. Content Roadmap (10 pontos)

### 6.1 Launch Content (5 pontos)
- [ ] **MVP definido** - Minimo viavel para lancamento (2 pts)
- [ ] **Content list completa** - Todos items/levels/features de launch (1.5 pts)
- [ ] **Horas de gameplay estimadas** - Quanto conteudo no dia 1 (1.5 pts)

### 6.2 Post-Launch Plan (5 pontos)
- [ ] **Update schedule proposto** - Frequencia de atualizacoes (1.5 pts)
- [ ] **Features futuras listadas** - Roadmap de 3-6 meses (1.5 pts)
- [ ] **Seasonal events planejados** - Eventos especiais considerados (1 pt)
- [ ] **Community feedback plan** - Como incorporar sugestoes (1 pt)

**Score Content Roadmap:** ____/10

---

## 7. Metrics Defined (10 pontos)

### 7.1 KPIs Core (6 pontos)
- [ ] **DAU/MAU targets** - Metas de jogadores ativos (1.5 pts)
- [ ] **Retention targets** - D1, D7, D30 esperados (1.5 pts)
- [ ] **Session length target** - Tempo medio de sessao (1.5 pts)
- [ ] **Revenue targets** - ARPU, ARPPU esperados (1.5 pts)

### 7.2 Game-Specific Metrics (4 pontos)
- [ ] **Metricas de engajamento** - O que medir para este jogo (1.5 pts)
- [ ] **Funnels identificados** - Pontos de conversao criticos (1.5 pts)
- [ ] **Success criteria claros** - O que define sucesso do jogo (1 pt)

**Score Metrics Defined:** ____/10
