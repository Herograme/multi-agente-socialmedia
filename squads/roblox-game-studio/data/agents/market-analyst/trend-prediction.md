## 1. Trend Identification Methodology

### The DETECT Framework

```
D - Discover: Find emerging signals
E - Evaluate: Assess trend potential
T - Track: Monitor development
E - Execute: Plan response
C - Capture: Implement strategy
T - Test: Validate and iterate
```

### Signal Types

| Signal Type | Description | Reliability | Speed |
|-------------|-------------|-------------|-------|
| **Weak Signals** | Early hints, niche activity | Low | Very Fast |
| **Medium Signals** | Growing mentions, emerging pattern | Medium | Fast |
| **Strong Signals** | Mainstream attention, clear growth | High | Medium |
| **Lagging Signals** | Everyone knows, saturation risk | Very High | Slow |

### Trend Categories

| Category | Definition | Examples | Typical Lifespan |
|----------|------------|----------|------------------|
| **Meme/Viral** | Internet culture driven | Brainrot, Skibidi | 2-8 weeks |

## 3. Viral Cycle Timeline

### Standard Viral Cycle

```
         EMERGENCE    ACCELERATION    PEAK    SATURATION    DECLINE
              │             │          │           │            │
ATTENTION  ───┼─────────────┼──────────┼───────────┼────────────┼───
              │        ╱──────────╲    │           │            │
              │      ╱              ╲  │           │            │
              │    ╱                  ╲│           │            │
              │  ╱                     │╲          │            │
              │╱                       │  ╲        │            │
           ───┼────────────────────────┼────╲──────┼────────────┼───
              │                        │      ╲    │            │
TIME       Day 1-3    Day 4-10    Day 11-21  Day 22-35    Day 36+
```

### Phase Characteristics

| Phase | Duration | Signals | Opportunity |
|-------|----------|---------|-------------|
| **Emergence** | 1-3 days | Niche creators, small view counts | First mover advantage |
| **Acceleration** | 4-10 days | Major creators pick up, trending | Best time to launch |
| **Peak** | 11-21 days | Mainstream awareness, saturation begins | Still viable, competition rising |
| **Saturation** | 22-35 days | Copycat explosion, declining engagement | Risky, differentiate hard |
| **Decline** | 36+ days | Negative sentiment, "dead" perception | Too late, move on |

### Roblox-Specific Timeline

```
VIRAL CONTENT → ROBLOX GAME TIMELINE:

Day 0:    Viral content emerges (TikTok/YouTube)
Day 1-3:  Content spreads, memes form
Day 3-7:  First Roblox games appear (quick devs)
Day 7-14: More games launch, some gain traction
Day 14-21: Market becomes crowded
Day 21-30: Winner emerges, others fade
Day 30+:  Trend normalizes or dies

OPTIMAL WINDOWS:
├── Ultra-fast dev (1-3 days): Days 3-7
├── Fast dev (1-2 weeks): Days 7-14
├── Normal dev (2-4 weeks): Usually too late for pure trend
└── Quality play: Ride second wave with better execution
```

### Trend Lifespan by Type

| Trend Type | Typical Lifespan | Peak Window | Example |
|------------|------------------|-------------|---------|
| Meme/Sound | 2-4 weeks | Days 5-15 | Skibidi |
| Character/IP | 1-3 months | Weeks 2-6 | Anime characters |
| Mechanic | 3-12 months | Months 1-4 | Among Us clone wave |
| Genre Shift | 6-24 months | Months 3-12 | Horror boom |
| Platform Change | Permanent | First 3 months | New Roblox features |

### Response Strategy by Phase

```
EMERGENCE RESPONSE:
├── Monitor closely
├── Assess fit and feasibility
├── Begin concept/prototype if viable
├── Don't over-commit yet
└── Set clear go/no-go criteria

ACCELERATION RESPONSE:
├── Commit resources if passing criteria
├── Rapid development sprint
├── Focus on core mechanic
├── Prepare marketing assets
└── Line up content creators

PEAK RESPONSE:
├── Launch if ready
├── Heavy marketing push
├── Iterate based on feedback
├── Capture market share fast
└── Plan for longevity pivot

SATURATION RESPONSE:
├── Only launch if highly differentiated
├── Focus on quality over speed
├── Consider alternative angle
├── Learn for next trend
└── Document what worked/didn't

DECLINE RESPONSE:
├── Don't launch trend-dependent game
├── Pivot existing game away from trend
├── Archive learnings
├── Watch for revival signs
└── Focus on evergreen opportunities
```

## 4. Leading vs Lagging Indicators

### Indicator Classification

| Indicator Type | Definition | Example | Action Trigger |
|----------------|------------|---------|----------------|
| **Leading** | Predicts future trend | Search volume spike | Early preparation |
| **Coincident** | Confirms current trend | CCU growth | Execute strategy |
| **Lagging** | Confirms past trend | Revenue data | Validate decisions |

### Leading Indicators for Roblox

```
SEARCH & SOCIAL SIGNALS:
├── Google Trends spike for related terms
├── TikTok sound usage acceleration
├── YouTube search volume increase
├── Reddit post frequency on topic
└── Discord discussion volume

CREATOR SIGNALS:
├── Major creator announces coverage
├── Multiple small creators simultaneously cover
├── Positive sentiment from tastemakers
├── Collaboration announcements
└── Content creator requests to developers

PLATFORM SIGNALS:
├── Roblox official mention/feature
├── Developer event announcement
├── API update related to trend
├── Partner program changes
└── Featured sort changes

DEVELOPER SIGNALS:
├── DevForum discussion spikes
├── Asset marketplace searches
├── Open-source project activity
├── Job postings for specific skills
└── Developer tool adoption
```

### Lagging Indicators (Confirmation)

```
GAME PERFORMANCE:
├── CCU stabilization
├── Revenue consistency
├── Retention metrics settling
├── Review sentiment normalization
└── Update fatigue appearing

MARKET SIGNALS:
├── Multiple established games in space
├── Clear market leaders emerged
├── Copycats flooding market
├── Content creator coverage declining
└── "Best of" lists crystallizing

PLAYER SIGNALS:
├── Feature expectations established
├── Price sensitivity known
├── Session length patterns stable
├── Monetization responses predictable
└── Community dynamics mature
```

## 8. Case Studies of Past Trends

### Case Study 1: Skibidi Toilet (Meme → Games)

```
TIMELINE:
├── Feb 2023: First Skibidi Toilet video posts
├── Mar-Apr 2023: Viral spread, meme explosion
├── May 2023: First Roblox games appear
├── Jun-Jul 2023: Market floods with games
├── Aug 2023: Peak saturation, quality winners emerge
├── Sep 2023+: Trend normalizes, niche remains

WHAT WORKED:
├── Fast development (first week)
├── Quality differentiation
├── Content creator partnerships
├── Continuous updates matching video releases
└── Brand building beyond single trend

WHAT DIDN'T WORK:
├── Late entries (after peak)
├── Low-quality copies
├── Single-mechanic games
├── No differentiation strategy
└── Abandoning quickly

LESSONS:
├── Speed matters for meme trends
├── Quality can win even late
├── Build beyond the trend
├── Update to match evolving source
└── Community is long-term value
```

### Case Study 2: DOORS (Genre Innovation)

```
TIMELINE:
├── Aug 2022: DOORS launches
├── Sep-Oct 2022: Organic growth, creator coverage
```
